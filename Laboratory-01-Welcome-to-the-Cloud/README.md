# Laboratory 01 – Welcome to the Cloud Computing

## Mission Overview

This laboratory activity introduces the fundamentals of cloud computing and provides hands-on experience with a Linux environment. The mission involves using a Linux playground, exploring the system environment, creating a user account, building a workspace, and documenting the activities performed.

## Objectives

- Launch and explore an Ubuntu Linux environment using KillerCoda.
- Create and configure a new Linux user account.
- Learn how to navigate and work with the Linux terminal.
- Investigate basic system information such as the Linux distribution, kernel version, CPU, memory, and disk space.
- Create a proper workspace and file structure for the laboratory activities.
- Document the commands and skills learned throughout the activity.

## Activities Performed

1. Launched an Ubuntu 24.04 Linux Playground using KillerCoda.
2. Verified that the Linux terminal was functioning correctly.
3. Created a new user account with a Bash shell, home directory, and sudo privileges.
4. Set a password for the new user and logged in to the new account.
5. Investigated the Linux environment and checked system information.
6. Created the required workspace folders: `Notes`, `Reports`, and `Screenshots`.
7. Created the required Markdown files for documenting the laboratory activity.
8. Created and organized the GitHub repository for the laboratory activities.

## Linux Commands Used

The following Linux commands were used during the laboratory:

- `whoami` – Displays the current logged-in user.
- `pwd` – Displays the current working directory.
- `ls` – Lists files and directories.
- `cd` – Changes the current directory.
- `useradd` – Creates a new Linux user.
- `passwd` – Sets or changes a user's password.
- `su` – Switches to another user account.
- `id` – Displays user and group information.
- `echo` – Displays text or environment variables.
- `cat /etc/os-release` – Displays Linux distribution information.
- `uname -r` – Displays the Linux kernel version.
- `lscpu` – Displays CPU information.
- `free -h` – Displays memory information.
- `df -h` – Displays available disk space.
- `mkdir` – Creates new directories.
- `touch` – Creates a new empty file.
- `nano` – Opens a terminal-based text editor.
- `find` – Searches for files and directories.

## Skills Learned

Through this laboratory activity, I learned how to work with a Linux terminal and perform basic system administration tasks. I learned how to create and manage user accounts, assign sudo privileges, navigate directories, create files and folders, and check system information. I also gained experience using KillerCoda as a Linux practice environment and organizing laboratory documentation using Markdown and GitHub.
