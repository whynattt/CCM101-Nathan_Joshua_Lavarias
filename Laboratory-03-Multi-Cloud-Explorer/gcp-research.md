# Google Cloud Platform Research

## Brief Overview

Google Cloud Platform (GCP), also known as Google Cloud, is a cloud computing platform that provides services for computing, storage, databases, networking, analytics, artificial intelligence, and application development. It uses Google's global infrastructure to provide scalable and reliable cloud services.

## Global Infrastructure

Google Cloud organizes its infrastructure into regions and zones. As of July 2026, Google Cloud provides 43 global regions and 130 zones across more than 200 countries and territories. Its global network and infrastructure are designed to provide high performance, reliability, and low latency.

## Cloud Management Console

The Google Cloud console is a web-based interface used to create, manage, monitor, and configure Google Cloud resources and services. It allows users to work with projects, compute resources, storage, databases, networking, security, and other Google Cloud services.

## Four Core Services

### 1. Compute Engine

Compute Engine is an Infrastructure-as-a-Service offering that allows users to create and run virtual machines on Google's infrastructure.

### 2. Cloud Storage

Cloud Storage is an object storage service designed to store secure, durable, and scalable data such as files, backups, and media.

### 3. Cloud SQL

Cloud SQL is a managed relational database service that supports database systems such as MySQL, PostgreSQL, and SQL Server.

### 4. Google Kubernetes Engine

Google Kubernetes Engine (GKE) is a managed environment for running and managing containerized applications using Kubernetes.

## Three Advantages

1. **Strong AI and machine learning capabilities** – Google Cloud provides extensive services and infrastructure for artificial intelligence and machine learning workloads.
2. **Data analytics** – Google Cloud provides powerful data analytics services such as BigQuery for processing and analyzing large datasets.
3. **Global network** – Google Cloud uses Google's global network and infrastructure to provide high performance, reliability, and global connectivity.

## Typical Enterprise Use Cases

Google Cloud is commonly used for artificial intelligence and machine learning, big data analytics, application hosting, containerized applications, database management, web applications, and large-scale cloud-native systems.
