# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform that provides services for computing, storage, databases, networking, artificial intelligence, security, and application development. Azure is widely used by organizations that already use Microsoft technologies and need cloud and hybrid-cloud solutions.

## Global Infrastructure

Azure has a large global infrastructure consisting of more than 80 Azure regions and more than 500 datacenters. Its global infrastructure helps organizations deploy applications closer to their users, meet data residency requirements, and build highly available cloud solutions.

## Cloud Management Console

The Azure portal is a web-based unified console used to create, manage, and monitor Azure resources. Users can manage virtual machines, databases, storage, networking resources, subscriptions, and other services through a graphical interface.

## Four Core Services

### 1. Azure Virtual Machines

Azure Virtual Machines provide scalable virtualized computing resources that can be used to run applications and operating systems in the cloud.

### 2. Azure Blob Storage

Azure Blob Storage provides object storage for large amounts of unstructured data such as documents, images, videos, backups, and other files.

### 3. Azure SQL Database

Azure SQL Database is a managed relational database service based on the Microsoft SQL Server database engine.

### 4. Azure Virtual Network

Azure Virtual Network provides private networking for Azure resources and allows organizations to securely connect cloud resources with other networks.

## Three Advantages

1. **Microsoft integration** – Azure integrates strongly with Microsoft technologies such as Windows Server, SQL Server, and Microsoft 365.
2. **Hybrid cloud support** – Azure provides tools and services for connecting on-premises infrastructure with cloud resources.
3. **Global infrastructure** – Azure provides a large number of regions and datacenters to support global applications and data residency requirements.

## Typical Enterprise Use Cases

Azure is commonly used for enterprise application hosting, Microsoft-based workloads, hybrid cloud environments, database management, virtual machines, data analytics, artificial intelligence, and business applications.
