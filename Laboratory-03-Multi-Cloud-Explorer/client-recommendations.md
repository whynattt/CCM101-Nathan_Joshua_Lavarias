# Cloud Platform Recommendation Challenge

## Client A – Startup Company

### Recommended Cloud Platform: Amazon Web Services (AWS)

I recommend **Amazon Web Services (AWS)** because the startup has a limited budget but expects rapid growth. AWS provides scalable services that allow the company to start with the resources it needs and increase them as the application grows. Its pay-as-you-go model can also help the startup avoid purchasing expensive hardware in advance. The company can use **Amazon EC2, Amazon S3, and Amazon RDS** to build and support its mobile application.

**Recommended Services:**
- Amazon EC2 – for running application servers
- Amazon S3 – for storing files and application data
- Amazon RDS – for managing the application's relational database

---

## Client B – University

### Recommended Cloud Platform: Microsoft Azure

I recommend **Microsoft Azure** because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure has strong integration with Microsoft technologies, making it easier for the university to migrate existing services to the cloud. It also supports hybrid cloud environments, allowing the university to connect its existing infrastructure with Azure. The university can use **Azure Virtual Machines, Microsoft Entra ID, and Azure Blob Storage**.

**Recommended Services:**
- Azure Virtual Machines – for running Windows-based applications and servers
- Microsoft Entra ID – for identity and access management
- Azure Blob Storage – for storing documents, files, and other data

---

## Client C – AI Research Company

### Recommended Cloud Platform: Google Cloud Platform (GCP)

I recommend **Google Cloud Platform (GCP)** because the company focuses on Artificial Intelligence and Machine Learning applications. Google Cloud has strong AI and data analytics capabilities that can support research and development workloads. It also provides scalable computing resources that can be used for high-performance workloads. The company can use **Google Compute Engine, Google Kubernetes Engine, and Vertex AI** for its AI and ML projects.

**Recommended Services:**
- Google Compute Engine – for high-performance computing workloads
- Google Kubernetes Engine (GKE) – for running and managing containerized applications
- Vertex AI – for developing and deploying AI and machine learning applications

---

## Client D – Global E-Commerce Company

### Recommended Cloud Platform: Amazon Web Services (AWS)

I recommend **Amazon Web Services (AWS)** because the company serves customers around the world and needs highly available and scalable infrastructure. AWS has a large global infrastructure with Regions and Availability Zones that can help support reliable applications. AWS also provides services that can automatically scale resources based on demand. The company can use **Amazon EC2, Amazon S3, and Elastic Load Balancing** to support its e-commerce platform.

**Recommended Services:**
- Amazon EC2 – for running the e-commerce application
- Amazon S3 – for storing product images, files, and other data
- Elastic Load Balancing – for distributing traffic across application servers


# Checkpoint 6 – Multi-Cloud Decision Matrix

## Cloud Provider Decision Matrix

| Business Requirement | Recommended Platform | Justification |
|---|---|---|
| Startup Company | AWS | AWS offers a wide range of services and scalable resources that can support a startup as it grows. |
| Enterprise Organization | AWS | AWS provides a broad selection of enterprise services, strong scalability, and global infrastructure. |
| Microsoft Environment | Microsoft Azure | Azure has strong integration with Microsoft products such as Windows Server, Microsoft 365, and Microsoft Entra ID. |
| AI / Machine Learning | Google Cloud Platform (GCP) | GCP is known for its strong AI, machine learning, and data analytics capabilities. |
| Kubernetes Deployment | Google Cloud Platform (GCP) | GCP provides Google Kubernetes Engine (GKE), a managed Kubernetes service for deploying and managing containerized applications. |
| Global Web Application | AWS | AWS provides global infrastructure, scalable computing, and services that can support highly available web applications. |
