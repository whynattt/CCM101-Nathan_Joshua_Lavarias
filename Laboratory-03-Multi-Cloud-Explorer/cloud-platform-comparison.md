## Questions and Answers

### 1. Which cloud provider offers the broadest range of services?

Amazon Web Services (AWS) offers the broadest range of cloud services among the three major providers. It provides many services for computing, storage, databases, networking, security, analytics, and other business needs.

### 2. Which provider best integrates with Microsoft technologies?

**Microsoft Azure** best integrates with Microsoft technologies. It works well with products such as Windows Server, SQL Server, Microsoft 365, and other Microsoft enterprise solutions.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud Platform (GCP) is strongest in Artificial Intelligence and Kubernetes. Google has strong experience in AI and data analytics, and it also provides Google Kubernetes Engine (GKE) for managing containerized applications.

### 4. Which cloud platform would you personally choose and why?

I would personally choose Amazon Web Services (AWS) because it offers a wide range of services and has many tools that can be used for different types of projects. As an IT student, learning AWS would also give me experience with many areas of cloud computing, such as virtual machines, storage, networking, and security.
