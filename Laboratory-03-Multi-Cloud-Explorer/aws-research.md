# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform that provides a wide range of services for computing, storage, databases, networking, security, analytics, and application development. AWS is designed to help organizations deploy and manage applications and infrastructure through cloud-based services.

## Global Infrastructure

AWS operates a global infrastructure organized into geographic Regions and Availability Zones. AWS currently has 39 geographic Regions and 123 Availability Zones. Each Region contains multiple isolated Availability Zones, which help organizations design applications with high availability and fault tolerance.

## Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services. It provides centralized access to individual AWS service consoles and allows users to manage resources, monitor services, view billing information, and access tools such as AWS CloudShell.

## Four Core Services

### 1. Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides resizable computing capacity through virtual machines. It can be used to run applications, websites, and other workloads in the cloud.

### 2. Amazon S3

Amazon Simple Storage Service (S3) is an object storage service used to store and retrieve files, backups, media, and other types of data.

### 3. Amazon RDS

Amazon Relational Database Service (RDS) is a managed relational database service that makes it easier to set up, operate, and scale databases.

### 4. Amazon VPC

Amazon Virtual Private Cloud (VPC) provides networking capabilities that allow users to create isolated virtual networks for their AWS resources.

## Three Advantages

1. **Wide range of services** – AWS provides services covering computing, storage, databases, networking, analytics, AI, security, and many other areas.
2. **Global infrastructure** – AWS provides Regions and Availability Zones around the world, supporting highly available and globally distributed applications.
3. **Scalability** – AWS allows organizations to increase or decrease cloud resources according to their workload requirements.

## Typical Enterprise Use Cases

AWS is commonly used by enterprises for web and application hosting, data storage and backup, database management, analytics, artificial intelligence, disaster recovery, and large-scale application deployment.
